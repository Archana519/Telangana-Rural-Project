# Documentation

| Folder | What is inside |
|---|---|
| `status/` | Where the project stands: completion status, audit, findings, checkpoint. **Start with `PROJECT_COMPLETION_STATUS.md`.** |
| `plans/` | Plans and proposals that are not yet approved. |
| `data/` | Where the data came from, licence notes and the input checks. |
| `guides/` | How-to notes (setup scripts, presentation maps, earlier cleanup report). |
| `village_template/` | Starting files for adding another village. |
| `DECISIONS.md` | The decisions made so far. |
